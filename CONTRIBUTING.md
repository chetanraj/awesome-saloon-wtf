# Contributing to Awesome Saloon.wtf

Thanks for wanting to contribute! This list exists because of the beautiful wave of nostalgia sites that appeared after [saloon.wtf](https://saloon.wtf).

## How to add a site

1. Fork this repository
2. Add your entry under the most relevant category in `README.md`
3. Use this format:

   ```markdown
   - [Name](https://example.com) - Short description of the vibe (Creator if known)
   ```

4. Keep the description short and focused on the *scene* (barbershop, truck, bus, dhaba, etc.)
5. Open a Pull Request

## Guidelines

- **Quality over quantity** — the site should have a clear nostalgic scene and decent execution.
- Check for duplicates before adding.
- Prefer sites that capture a specific Indian everyday vibe (saloon, truck, roadways bus, chai tapri, baraat, regional language, etc.).
- Broken links or low-effort clones will be rejected.
- New categories are welcome if they make sense.

## Reporting issues

Found a dead link or something that no longer fits? Open an issue or submit a PR to fix it.

Thank you for helping keep this list alive! 🙏
