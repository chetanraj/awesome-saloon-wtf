[![License: CC0](https://img.shields.io/badge/License-CC0-lightgrey.svg)](https://creativecommons.org/publicdomain/zero/1.0/)

> A curated list of awesome **saloon.wtf**-inspired nostalgia music websites  
> Indian barbershop, truck, bus, railway, dhaba, wedding & regional vibes

---

**The trend started on 8 August 2026** when Mumbai-based designer **Yash Bhardwaj** ([@ybhrdwj](https://x.com/ybhrdwj)) launched [saloon.wtf](https://saloon.wtf) — a minimal website that plays the exact 90s Bollywood bangers once heard in neighbourhood “saloons” (₹20 haircuts, simple hairstyles, music that could fix your soul).

Within days it crossed a million visits and spawned hundreds of scene-based music players across India. This list collects the best ones.

## 💈 Barbershop / Saloon / Cutting Shop

## Contributing

Contributions are very welcome!

1. Fork the repository
2. Add your site under the most appropriate category (or create a new one if needed)
3. Use the format:
   ```
   - [Name](https://link) - Short description (Creator if known)
   ```
4. Keep quality high — the site should have a clear scene/vibe and good execution
5. Open a Pull Request

Please check for duplicates first. Low-effort or broken sites will not be merged.

See [CONTRIBUTING.md](CONTRIBUTING.md) for more details.
